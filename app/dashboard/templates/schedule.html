How this actually runs on a schedule

Render and Railway cron jobs only accept UTC cron expressions with no timezone/DST awareness. Based on your current settings, the equivalent UTC cron expression is:

{{ utc_cron }}

Paste this into the platform's Cron Job schedule field, with the command python -m app run. For Asia/Kolkata (no DST) this expression is exact and permanent. If you switch to a DST-observing timezone, you'll need to update it twice a year -- or run python -m app scheduler instead, which is timezone- and DST-aware but requires a process that stays running (not suitable for Render/Railway's cron job type, which is meant to start, run, and exit).
